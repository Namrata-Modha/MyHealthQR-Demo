## 💡 Project Summary

**MyHealthQR** is a privacy-compliant health information system that uses QR codes to share critical data in emergencies. Built with Laravel and PostgreSQL, the platform features secure login, email verification, dynamic profile control, and activity logging.

## 🛠️ Technologies Used
- Laravel
- PostgreSQL
- Bootstrap
- JavaScript (jQuery Validation)
- Git LFS (for media files)
